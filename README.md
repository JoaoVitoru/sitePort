## Tecnologias do site
- HTML5 semântico

- JavaScript puro (sem frameworks)
- Ícones: [Devicon](https://devicon.dev/)

## Publicar no GitHub Pages
1. Envie o repositório para o GitHub.
2. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`.
